## איך מעלים עדכון לאוויר

האתר סטטי לחלוטין (HTML/CSS/JS בלבד) ומתארח על **GitHub Pages**.
כל דחיפה ל-`main` מתפרסמת אוטומטית תוך כדקה.

**העלאה ידנית דרך הדפדפן:**
1. נכנסים לריפו ב-GitHub → `Add file` → `Upload files`
2. **חשוב:** נכנסים *לתוך* התיקייה במחשב, בוחרים הכול (`Ctrl+A`) וגוררים את **התכולה** —
   לא את התיקייה עצמה (אחרת הכול יורד רמה והאתר יחזיר 404)
3. לוודא ש-`View → Show → Hidden items` דלוק בסייר הקבצים, אחרת `.nojekyll` לא יעלה
4. `Commit changes`
